# AgentIsland 项目交接与路线图

本文面向接手的开发者和 AI，记录截至 2026-11-05 的项目方向、验收结果与待办。它是开发快照，不代表已正式发布；接手时请重新核对实际代码、运行版本与仓库状态，不要把旧文档中的推断当作当前事实。

## 产品目标与原始设想的区别

- 最初计划使用 MacBook 键盘背光显示 AI 的执行、待操作和完成状态。由于背光效果及视线切换问题，用户已取消该功能，不要重新引入；旧目录或历史文档中的 AiKeyboardLight／背光是历史名称和设想。
- 现在的产品叫 AgentIsland，是 macOS 菜单栏与灵动岛式悬浮窗。它聚合 AI 助手状态和待处理问题；在能确认目标会话和问题时，支持从面板回复。Antigravity 多会话按纵向分行。
- 第一阶段重点是 Codex Desktop 和 Antigravity 的可靠状态与安全回复；Claude、Cursor、Windsurf、Trae 为实验性适配，不应宣称均已完成发布验收。
- 目标是最终让他人方便下载安装与使用，并准备开源；在关键回归、干净环境及发布审查完成前，不把预览版称为正式版或开箱即用。

## 已实现与已知验证范围

- 应用和 Codex／Antigravity 的主要集成使用 Swift；原生 Hook 记录器和配置入口不要求终端用户安装 Python。开发测试及部分实验性助手工具仍使用 Python。最低目标 macOS 14，使用 Swift 6。
- Codex 已有状态、问题、文字回复与一次性审批接口；单台 Mac 的隔离版曾验证无害问题超过 30 秒后选项回传，以及与 Antigravity 同时等待并分别回传。某次正在执行的真实任务中隔离版曾显示“执行中”，不代表所有状态组合已经可靠。
- Antigravity 2.28.2 在一台 Mac 的隔离版中，用户验证了两个会话的选项和文字分别送入正确会话并更新状态；点击完成／已查看可逐会话确认。点击原应用中的会话来确认属于实验功能：用户在隔离诊断版的双会话测试确认只清除被点击会话；普通隔离版及其他环境仍需复测。
- Antigravity 后台回复依赖未公开本机接口。当前代码仅允许 2.27.0、2.28.0、2.28.2；更新到未列出的版本后，后台回复会暂停并提示用户回原应用处理，状态监控可能继续。不能因版本号接近就跳过协议和回归验证。
- 提前验证问题默认关闭，需要用户另行启用；后台回复需用户同意读取 Antigravity 本机临时令牌。详见 [隐私说明](../PRIVACY.md)。
- 以上是特定环境和测试场景的结果，不代表所有助手版本、审批操作、安装方式或干净系统均已验证。

## 最高优先级：Codex 历史问题仍出现

用户最新反馈 Codex 仍显示一堆历史问题，有时旧问题会遮盖执行中状态。此前隔离代码增加了对完整历史中较早、已完成轮次异步问题的隐藏逻辑，但实际问题仍然存在；根因、正在运行的应用是否对应最新源码、不同来源的请求是否重复，都尚未确认。不要宣称已修复。

用户的明确选择是：自动隐藏已经结束且有更新轮次的旧问题；保留最新轮次真正未答的问题。隐藏只影响 AgentIsland 的展示，不能替用户回答、取消或删除 Codex 问题。历史不完整、会话或问题身份无法可靠确认时，应保守处理并解释原因。

建议依次检查运行的应用路径与构建版本、桌面 IPC 快照和 Hook／日志来源、会话及请求 ID 对应、完整历史是否实际加载、合并去重与状态优先级；先用合成数据复现，避免记录或公开真实问题、令牌、路径及会话内容。修复后同时验证运行中黄色、真实待答红色、旧问题隐藏、多个会话隔离、重启以及无害回复送达，不可只以单元测试通过作为完成标准。

## 架构入口

- `Sources/AgentIsland/Observers/CodexObserver.swift`、`CodexNativeBridge.swift`、`CodexDesktopBridge.swift`：Codex 状态、历史、请求和本机 IPC。
- `Sources/AgentIsland/Observers/AntigravityObserver.swift`、`AntigravityLocalTransport.swift`、`AntigravityReplyWorkflow.swift`：Antigravity 状态、版本限制、会话识别与回复。
- `Sources/AgentIsland/App/AntigravityViewedMonitor.swift`、`AntigravityActionController.swift`：会话完成确认和操作；`Sources/AgentIsland/Views/` 管理 UI。
- `Sources/AgentIsland/Observers/HookStateStore.swift`、`Sources/AgentIslandHook/`：事件状态和原生 Hook；安装、卸载和宿主配置必须先在模拟目录验证。
- `Tests/`、`scripts/test.sh`、`scripts/build_isolated_preview.sh`、`scripts/check_public_source.py`：测试、隔离构建与基础隐私扫描。具体构建及安装方法见 [README](../README.md) 和 [预览包说明](preview-install.md)。

## 工作边界与安全

保护用户正在使用的日常应用、真实助手配置和既有会话。先备份未提交／未跟踪源码、运行应用和将受影响的配置；使用独立目录、隔离构建、模拟 Hook 配置及无害问题验证。未经确认不覆盖日常应用、不更改真实助手配置、不执行真实命令审批。

仓库存在不同副本及历史：当前开发副本可能包含未提交修改；干净发布候选与原有私有仓库 `main` 不是同一份内容。GitHub 专用备份分支不等于正式发布；不能直接公开旧历史，也不能假定任一打包文件与最新源码一致。同步前先检查差异和隐私，发布前对同一提交的源码、完整历史、构建产物、文档、截图和元数据重新审查。常规扫描无法证明没有任何个人信息或安全问题。

## 后续顺序

1. 先定位并修复 Codex 历史提醒和错误状态，在隔离环境完成自动及无害实机回归，同时保持 Antigravity 的回复和多会话行为。
2. 重新验证 Antigravity 普通隔离版的完成确认、多会话隔离、版本更新后的提示、权限以及提前验证开启／关闭的行为；未经确认时回原应用处理。
3. 固定一个候选提交，重复测试，构建独立包，核对 App、校验值、README 与提交一致；扫描源码、构建物、历史和演示素材，人工审查第三方素材与个人信息。
4. 在干净 macOS 用户、虚拟机或另一台 Mac 验证下载、首次启动、授权、两款助手、Hook 安装卸载和不安装 Python 的正常路径。用户目前选择暂缓这项测试，所以它仍是发布前的未完成验收。
5. 决定 Apple Developer ID 签名与公证；如先发未公证预览，说明 macOS 提示、身份核验及辅助功能可能需要重新授权，不要求关闭全局安全设置。
6. 完成 README、隐私／安全、卸载、MIT 许可证、第三方授权、问题反馈和公开版本说明；准备经隐私审查的 GIF／视频。赞助链接在本人完成收款、提款和身份展示检查后启用。
7. 用户最终审阅代码、发布包和公开内容后，再进行公开或发布。所有对外承诺以实际验收为准。
